# GFG Clone 🌐

A responsive **GeeksforGeeks (GFG) Clone** website built using **HTML, CSS, and Bootstrap**.

This project is created for learning and practicing frontend web development concepts such as webpage structure, responsive design, navigation bars, cards, layouts, and Bootstrap components.

## 🚀 Technologies Used

* **HTML5** - Used to create the structure of the website.
* **CSS3** - Used for custom styling and page design.
* **Bootstrap** - Used for responsive layouts and UI components.

## ✨ Features

* Responsive website design
* GFG-inspired navigation bar
* Homepage layout
* Course and learning sections
* Cards and content sections
* Responsive design using Bootstrap
* Custom CSS styling
* Clean and simple user interface
